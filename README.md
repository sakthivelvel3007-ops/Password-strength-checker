Password Strength Checker

Project Description

The Password Strength Checker is a Python-based application that evaluates the strength of a password based on basic security requirements. It checks whether the password contains a minimum of 8 characters, uppercase letters, lowercase letters, numbers, and special characters.

The program calculates a security score out of 5 and classifies the password as Weak, Medium, Strong, or Very Strong. It also provides suggestions to improve password security if any requirements are missing.

Objectives

- Check password length.
- Identify uppercase and lowercase letters.
- Verify the presence of numbers and special characters.
- Calculate a password security score.
- Display the password strength level.
- Provide suggestions to improve password security.

Technologies Used

- Python
- "re" module for pattern matching.
- "getpass" module for securely accepting password input without displaying it in the terminal.

Features

- Password strength evaluation.
- Security score out of 5.
- Strength meter using star symbols.
- Personalized suggestions for missing requirements.
- Hidden password input in the terminal.

Password Strength Levels

- Very Strong: All five checks pass, and the password contains at least 14 characters.
- Strong: At least four checks pass, and the password contains at least 8 characters.
- Medium: At least three checks pass.
- Weak: Does not meet the minimum requirements for the other levels.

How to Run

1. Install Python on your computer.

2. Save the program as "password_strength_checker.py".

3. Open a terminal or command prompt.

4. Navigate to the folder containing the Python file.

5. Run the following command:
   
   "python password_strength_checker.py"

6. Enter your password when prompted.

7. View the security score, password strength, and suggestions.

Conclusion
